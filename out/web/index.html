Blockchain Notary

File ở lại với bạn, bằng chứng nằm trên sổ cái. Trình duyệt chỉ gửi hash SHA-256, không gửi nội dung file.

Thả file vào đây hoặc bấm để chọn file (hợp đồng, bằng cấp, chứng chỉ…)
Tên file
Kích thước
SHA-256

Thả file vào khung phía trên, hệ thống tính lại hash rồi đối chiếu với sổ cái.

Bản demo học tập: sổ cái chạy cục bộ trên máy bạn. Hệ thống chứng minh toàn vẹn và thời điểm; danh tính ngoài đời cần eKYC hoặc công chứng.
